# Thought Translate

Translation that mirrors thought, not words.

A document translation and human-correction platform for Indian languages. Accepts pasted
text or real documents (PDF, DOCX, XLSX, CSV, and scanned images via OCR), preserves document
structure through translation, and returns output in the original file format. Reviewers can
comment on and correct specific phrases in a translation, with each accepted correction
retained as structured data.

- `backend/` — FastAPI (Python)
- `frontend/` — React + TypeScript + Vite
